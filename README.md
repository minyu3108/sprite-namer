# 立繪差分命名器

幫立繪差分圖批量命名，也能把分開的圖層合成各種差分。所有處理都在瀏覽器內完成，圖片不會上傳。

## 快速開始

1. 開啟網頁，把圖片直接拖進來。
2. 「命名」分頁：排好順序，輸入角色名字與形容，下載 ZIP。
3. 「合成差分」分頁：第一次使用可按「載入範例」看看流程。

支援直接拖入：圖片檔、`.zip`、`.json`、`.psd`。

## 命名

- 拖曳排序，編號與檔名會即時更新。
- 檔名由「名字、編號、版本、形容」等方塊組成，可拖曳調整順序，也能存成自己的格式。
- 可建立多個版本（例如本體、戴帽子），並把形容同步到其他版本。
- 下載 ZIP；也能匯入之前下載的 ZIP 或 `sprite-namer.json`，還原整個專案。
- **去背**：自動偵測背景色去背，再用筆刷擦掉或補回；可一次套用到整個版本。
  勾選「半透明去色」後，背景區域會變成半透明，不是整片刪掉，適合線稿（效果類似愛筆思畫）。

## 合成差分

- 把圖層疊在一起，一次輸出各種表情與配件的組合。圖層必須是畫布大小相同、位置對齊的 PNG。
- 圖層分成圖層組，每組可選「每張都一樣」、「分成版本」、「分成差分」，頁面會即時顯示會輸出幾張。
