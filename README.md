# 立繪差分命名器

批量替立繪差分圖加上名字與編號的單檔網頁工具。

- 拖曳排序，編號與檔名即時更新
- 點圖片放大並輸入形容
- 檔名格式由方塊組成，可拖曳調整順序
- 多個版本（例如本體、戴帽子），可複製版本保留格式與形容
- 匯出 ZIP（原圖加新檔名），可選擇是否按版本分資料夾
- 所有處理都在瀏覽器內完成，圖片不會上傳

## 使用

直接用瀏覽器開啟 `index.html`，或用 GitHub Pages 發佈：
Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`。

格式與「我的格式」存在瀏覽器的 localStorage，換瀏覽器或裝置不會跟著走。
