# 立繪差分命名器
 
批量替立繪差分圖加上名字與編號，也能把分開的圖層合成各種差分的單檔網頁工具。
所有處理都在瀏覽器內完成，圖片不會上傳。
 
## 功能
 
### 命名
- 拖曳排序，編號與檔名即時更新
- 點圖片放大並輸入形容
- 檔名格式由方塊組成，可拖曳調整順序，也可存成「我的格式」
- 多個版本（例如本體、戴帽子），可複製版本，並可把形容同步到其他版本
- 匯出 ZIP（原圖加新檔名），可選擇是否按版本分資料夾
- 可匯入之前下載的 ZIP 或 `sprite-namer.json`，還原版本、名字、格式、順序與形容
### 合成差分
- 把分開的圖層（PNG，畫布大小相同、位置對齊）疊起來，一次輸出各種表情與配件的組合
- 圖層分成圖層組，每組可選「每張都一樣」、「分成版本」、「分成差分」，並即時顯示會產生的張數
- 單選圖層組可加入「沒有」選項，只有一個圖層（例如帽子）也能分成有／沒有
- 圖層組可自動命名（頭髮1、頭髮2…），圖層可拖曳到其他圖層組
- 可匯入 PSD（資料夾變成圖層組），也可把整理好的圖層匯出成 PSD
- 可存成組合清單逐一指定，或自動展開全部組合
- 合成後自動送到「命名」分頁；名稱相同的版本會併入既有版本
### 圖片檢視
- 合成預覽與圖層縮圖都可點開大圖，滾輪縮放、拖曳移動、雙擊還原
- 預覽底色可切換（棋盤、白、黑、灰、綠），方便辨認透明圖
### 畫面
- 亮色（冰雪・極光）與暗色（拿鐵星夜）兩套配色，預設跟隨系統，可手動切換
- 背景粒子動畫（暗色為星光、亮色為雪花），可關閉；點擊粒子會爆開消失
- 「簡潔配色」可切成單色、無動畫的配色
- 系統設為「減少動態效果」時，動畫自動停止
## 支援的檔案
 
可直接拖入：圖片檔、`.zip`、`.json`、`.psd`。
 
- 圖片檔：兩個分頁都可使用
- `.zip`、`.json`：在「命名」分頁還原專案
- `.psd`：在「合成差分」分頁匯入圖層（愛筆思畫請匯出「PSD（保留圖層）」）
## 使用
 
直接用瀏覽器開啟 `index.html`，或用 GitHub Pages 發佈：
Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`。
 
格式、我的格式與畫面設定（亮暗模式、配色、動畫、預覽底色）存在瀏覽器的 localStorage，換瀏覽器或裝置不會跟著走。
 
匯入與匯出 PSD 使用 [ag-psd](https://github.com/Agamnentzar/ag-psd)，第一次用到時才從 CDN 載入。
